TALAL MUSIC - Starter Project

یہ ابتدائی PWA ڈیمو ہے، مکمل streaming سروس نہیں۔
اس میں اصل گانوں کی آڈیو شامل نہیں۔ قانونی Music API اور Hosting بعد میں جوڑنی ہوگی۔

آسان ترین طریقہ:
1) اس ZIP کو Extract کریں۔
2) GitHub پر مفت اکاؤنٹ بنائیں۔
3) New repository بنائیں، نام talal-music رکھیں۔
4) اس فولڈر کی تمام فائلیں repository میں Upload files کے ذریعے اپ لوڈ کریں۔
5) Settings > Pages > Deploy from a branch > main > /(root) منتخب کریں۔
6) Save کریں۔ GitHub آپ کو ویب لنک دے گا۔
7) Android پر Chrome سے لنک کھولیں، Add to Home screen کریں۔
8) iPhone پر Safari سے لنک کھولیں، Share > Add to Home Screen کریں۔

نوٹ:
- اس ڈیمو میں گانوں کے نام صرف مثال کے طور پر ہیں، آڈیو چلانے کے لیے مجاز provider/API درکار ہے۔
- مشہور گانوں کے YouTube لنکس دکھانا ممکن ہے، لیکن YouTube کی پالیسی کے مطابق اس کا سرکاری player استعمال کرنا ہوگا۔
- Public link کا مطلب ہے کہ لنک رکھنے والا کوئی بھی شخص اسے کھول سکتا ہے۔
